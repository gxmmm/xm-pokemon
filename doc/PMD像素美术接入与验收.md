# PMD 像素美术接入与验收

## 范围与产品决定

按开发者确认，全作角色、场景与任何特效统一像素风；仅面向桌面全窗口。本轮全量接入第一世代 151 只，图鉴、队伍、详情与战斗共用新的素材。皮皮、皮可西的 Dance 六帧通过抬手／舞动施法候选验收，两只均保留。

五种战斗环境由像素地面、树林、浅滩、石墙、晶柱及竞技场构件组成，不再加载旧 AI 背景。旧图片仅作为未被正式环境引用的历史资源保留。

## 来源与可重建性

- 上游：[PMDCollab/SpriteCollab](https://github.com/PMDCollab/SpriteCollab)，固定版本 `1f201ba3f969dd0eb4447744dffaeaaef26f5ae7`。
- `scripts/import-pmd-battle-assets.py` 下载源动作图、Offsets、Shadow、AnimData 和 credits；原文件缓存于 `art-source/pmd-source-v1`，不要求发布缓存。
- 发布目录为 `apps/web/public/sprites/pmd-v1`：每只包含正反图集、JSON、静态图标、credits.txt 和 source.json。上游许可证、README 和署名索引保留在目录根部。共约 4.7 MB，包括 302 个方向图集；仅按实际角色加载。
- 运行 `python scripts/import-pmd-battle-assets.py` 重建全量；需 Python 与 Pillow。可用 `--species 35,36` 重建指定角色。生成尺寸表由脚本统一刷新，资源路径仅由 config manifest 提供。
- 社区素材的上游许可证为 CC BY-NC 4.0；具体原作者与既有官方素材的说明以随附上游许可证及各角色署名记录为准，角色 IP 权属没有因转换而改变。

## 动作与挂点

Idle、Walk、Attack、Hurt 全量可用。149 只采用 Shoot 或其源别名，35／36 使用 Dance。28 只采用源 Faint，其余 123 只使用 Hurt 加统一降低透明度兜底。

正面使用源第 7 方向，背面使用第 3 方向；逐帧按 Shadow 白色原点对齐。元数据保留黑色头点、绿色身点，舞动施法从红／蓝手点选择朝向目标的一只手。其他嘴点由头点加小偏移近似；并非 151 只均经过逐像素口型标定。

每个源时长单位为 1/60 秒，使用重复图集索引保留相对时长，无重复像素图。按源 HitFrame／ReturnFrame 拆分准备、释放与收招；准备和持续施法可保持最后一帧。有限动作适配既有表现阶段时长，不改变 castTime、可打断窗口、伤害及命中时序。角色原生姿态取代旧的整图拉伸、额外前冲与浮动。

## 统一特效

`PixelGraphics` 为光球、烟块、水波及弧线生成阶梯轮廓；投射、命中、光束、辅助与环境反馈共用。火焰 shader 改为离散轮廓及四档色块，水枪改为角状水块，俯冲头部环改为碎闪。落石为深浅不规则岩块，月亮之力为分层小球，妖精之风为错开的风屑，命中碎片随变体区分。元素小粒子分别保留火苗、水滴、叶片与短电弧的形状。

持续状态沿用多处小火苗、紫烟、短电弧、局部冰晶与头顶像素标识，无身体装饰环。世界与战斗统一 2 CSS 像素输出；角色纹理采用最近邻采样，界面文本维持原生分辨率。所有生命周期仍由原表现时钟控制。

## 验收证据

- `npm run smoke`：全 151 profile、302 方向图集的尺寸、帧索引、核心动作与挂点校验；原生尺寸／脚点／动态嘴点／源时长保持；动作排队、命中、状态、清理与引擎回归。
- `npm run visuals:battle -- --skills-only`：六个技能效果族，加皮皮、皮可西、小磁怪、大岩蛇，共 10 种角色技能组合的正反飞行与命中 40 个样本。产物在 `doc/visual-baselines/battle/skills-after`。
- 完整 `npm run visuals:battle` 覆盖场景切换、反复进入退出、持续运行、密集 3v3、五种地形、全部异常与接地遮挡；桌面尺寸另由 `--spacing-only` 验证。
- 浏览器采用 Chrome / SwiftShader，作为功能和画面回归，不代表真实显卡性能。没有把所有 151 只的全部动作逐帧人工审片作为已完成项；全量结构校验与代表角色视觉验收分开记录。

### 2026-09-11 收口结果

`typecheck`、`build`、`smoke`、完整 `visuals:battle`、`--skills-only`、`--natural-only`、`--spacing-only` 与 `playable:browser` 均通过。正式世界／战斗在 1366×768、1440×900、1920×1080 保持全窗口；队伍、炼妖、详情、图鉴、设置及捕捉／返回联动检查通过。完整战斗检查 6 轮进入／重开／退出、15 次环境切换及 60 秒持续采样，无残留帧任务、观察器或控制台错误，预热后 JS 堆增量约 0.63 MiB。

产品抽验结论：角色和五环境通过；补齐三种弹体形状与异常最小像素后，本轮视觉必修项关闭。异常最小像素统一为 2，保持小火苗和局部纹样，不扩大为身体光罩。原始截图在 Git 忽略的 `doc/visual-baselines` 下，正式页面代表图为 `playable/full-window-battle-1440.png`。
