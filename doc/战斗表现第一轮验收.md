# 战斗表现第一轮：密集范围技能可读性

## 产品需求

固定 3v3 中，火、水、精神范围技能同时覆盖三个目标时，角色轮廓与睡眠标记仍可辨认。所有目标保留反馈，不能通过漏播、错开实际命中或改变战斗事实换取画面清晰。

范围由产品角色提出并确认，开发负责实现与测试，产品独立审阅本轮截图和报告后验收。

## 实现边界

- 范围爆发采用普通透明混合，保留元素颜色；调整最大扩散半径、火焰核心覆盖和精神光环数量。
- 参数集中于 `BATTLE_EFFECT_COMPOSITION`，通用绘制函数消费配置。
- 实际伤害的独立命中特效、技能数值、引擎结算、动作时序、目标选择与资源清理规则保持原有行为。
- 沿用现有资源，不新增素材、物种分支或渲染器开关。

## 验收清单

| 检查项 | 判定依据 |
|---|---|
| 密集范围技能 | 标准与减少闪烁模式各采样 80 / 160 / 320 ms；角色与睡眠标记可辨认，前景没有大片泛白 |
| 目标完整 | 每次三个范围技能覆盖三个目标，前景、地面光圈及环境反馈共 27 个效果；结束后全部释放 |
| 范围覆盖预算 | 火、水、精神、电系在低／高强度的整个生命周期保持目标局部边界，精神光环保留元素颜色 |
| 动作及事实一致 | 连续动作、重复受击、真实中断，以及飞行／命中／扣血／倒下／控制恢复沿用浏览器时序断言 |
| 正式页面 | 倍速、暂停、跳过、结算一次性及 390px 页面回归 |
| 生命周期 | 加载中退出、6 轮重开退出、15 次环境切换及 60 秒持续采样 |

## 本地产物

生成文件均位于 Git 忽略的 `doc/visual-baselines/`：

- `battle/before-composition/`：本轮修改前重新运行得到的 160 ms 标准／减少闪烁截图及报告。
- `battle/readability-spread-*.png`：修改后的相位截图，其中无时间后缀的文件为 160 ms。
- `battle/motion-*.png`、`battle/outcome-*.png`、`battle/readability-*.png`：动作、结算与状态回归证据。
- `battle/report.json`：浏览器验收结果及相位采样记录。
- `playable/`：正式页面隔离验收结果。

浏览器使用 Chrome / SwiftShader；结果证明功能与生命周期回归，不代表真实显卡帧率或长期压力测试。

## 本轮验收结果（2026-09-05）

产品独立验收通过。逐张对比本轮修改前的两张 160 ms 截图与修改后的六张相位截图：标准模式中妙蛙花面部、卡比兽面部和腹部、皮卡丘头部的近白覆盖收敛，三目标的元素色和环形反馈均保留，六只角色和睡眠标记可辨。320 ms 前景消退后地面反馈仍可见；减少闪烁模式反馈更淡但未消失。

- `typecheck`、`smoke`、`build` 全部通过。
- `visuals:battle` 通过：报告生成于 `2026-09-05T03:26:05.057Z`，六条范围采样各 27 个效果，控制台错误为空；6 轮、15 次环境切换、60 秒持续采样完成，堆内存差值为 395160 字节。
- `playable:browser` 通过：报告 `passed: true`、`pageErrors: []`；倍速、暂停跳过、结算一次性、自然结束、390px 关键操作和页面布局回归通过。

本轮通过的是通用范围爆发表现调整及上述回归；同一效果被单目标范围技能复用时也会应用新表现。三相位视觉审阅不等于所有技能、所有阵容或真实 GPU 性能验收。
