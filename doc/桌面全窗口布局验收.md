# 桌面全窗口布局验收

日期：2026-09-07。范围：正式外部页面、世界与战斗，沿用仅桌面端与统一视觉标准。

## 需求与实现

- 移除固定 1280×800 舞台缩放、外框和黑边，应用使用整个浏览器内容区域。
- 世界与战斗的画布延伸到窗口四边，取消世界场景的最大宽度、固定宽高比，以及战斗场景的边框和两侧占位列。
- 地图标题、地图与治疗按钮、双方状态卡、战斗控制悬浮显示。空白 HUD 容器不拦截指针，内容页面保留必要卡片与弹窗。
- 地图和角色等比投影；世界连续背景补齐窗口，原地图范围完整保留。建筑按实际图形边界留出余量，修复灯塔顶部在 16:9 窗口下被裁切的问题。
- 技能说明移至文档层，按实际窗口坐标定位，避免滚动面板与旧舞台缩放影响定位。

本次只调整 Vue/CSS 布局和 renderer 取景，不改变移动坐标、碰撞、遭遇、伤害或结算规则。世界沿用当前程序化场景美术。

## 验证范围

- `npm run playable:browser`：正式世界和战斗连续调整为 1366×768、1440×900、1920×1080；验证应用、主区域、场景和画布的四边位置、无边框、实际画布像素尺寸、单画布实例。真实点击地图开关与治疗按钮，键盘左右移动后回到原位。
- 同一页面回归保留倍速、暂停/继续、跳过、捕捉/放生/失败结算与返回、自然战斗，以及队伍、炼妖、详情、图鉴、设置、菜单和技能说明操作。
- `npm run smoke`：世界六个配置场景及空场景在上述三尺寸和 1920×800 下，验证等比投影、完整地图、建筑图形边界与全窗口连续背景；保留既有玩法与资源生命周期测试。
- `npm run visuals:battle`：六轮进入/重开/退出、五环境、持续 60 秒、命中/倒下同步、密集战斗、镜头及投影回归。已通过，报告时间为 `2026-09-07T04:20:33.314Z`，页面错误为零，无遗留帧或观察器。随后灯塔修复仅影响世界取景，由下述复跑覆盖。
- 灯塔修复后，`npm run typecheck`、`npm run smoke`、`npm run build` 和 `npm run playable:browser` 全部通过；页面报告于北京时间 12:25 更新，`passed=true`、`pageErrors=[]`。

截图与 JSON 报告位于 Git 忽略的 `doc/visual-baselines/playable/` 和 `doc/visual-baselines/battle/`。关键图片为 `full-window-world-{1366,1440,1920}.png` 与 `full-window-battle-{1366,1440,1920}.png`。

## 产品验收

独立产品已检查三尺寸战斗，以及队伍与详情页面：背景铺满，无场景外框，HUD 与主要角色区域分离。首次检查发现的世界灯塔裁切已修复；重新查看三尺寸世界截图后，确认灯塔顶部完整且有留白，人物与 HUD 未裁切，场景四边无黑边或外框。最终产品验收通过，无剩余阻断项。

本轮桌面布局与操作验收不代表真实显卡性能验收；浏览器使用 Chrome / SwiftShader。固定站位截图未穷举所有移动位置和技能峰值，大体型队内重叠不在本轮布局修改范围。
