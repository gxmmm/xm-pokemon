# 六类技能样板精修

> 平台范围更新：2026-09-07 起仅支持桌面端，历史手机窄屏截图与通过记录仅留作历史证据，不再作为后续验收要求。

## 本轮范围

以喷射火焰、水枪、十万伏特、暗影球、破坏光线、空手劈作为六类正式战斗样板。沿用已有动作准备、释放、命中、恢复链路；火焰与暗影球的专用表现作为参照，本次集中改善水流、光束、电击及近战接触细节。

- 水流按发射方向绘制收尖的水体和尾滴，保留蓝色，命中变为局部水花。
- 十万伏特保留分段电弧、分叉和既有飞行接触时序，改用普通混合保留黄色，命中使用少量短电弧。
- 通用光束快速点亮主束、稳定保持后淡出，保留流动亮纹；破坏光线使用暖色能量束，去掉末端装饰圆环；精神光束的完整环改为短纹。
- 空手劈使用收尖短弧，按施法者身体挂点到接触点的方向旋转；碎片减为辅助。已有爪、尾、踢等方向性命中图形也沿来向旋转。

不改变技能数值、冷却、权威站位、伤害与控制结算时机。参数与技能映射位于静态配置；renderer按通用变体绘制，无物种或技能ID分支，不新增素材资产。

## 证据与边界

`npm run visuals:battle -- --skills-only` 通过正式BattleDirector、BattleStage和既有靶场事件构造采样。前后使用相同固定站位；飞行采样为释放后60ms或命中前50ms中较晚者，命中采样为命中后80ms。

- 修改前基线仅含六个正向飞行截图，位于 `doc/visual-baselines/battle/skills-before`。
- 修改后覆盖六技能正反两向的飞行与命中；共24张，位于 `skills-after`；早期减少闪烁样本不属于最终验收。
- 同目录的 `six-skills-preview.png` 是浏览器对真实截图局部的排版汇总，便于审阅；单张原始截图保留完整战场。
- 方向回归检查横向和竖向水流轮廓，以及不同攻击来向下近战接触点固定、280ms反馈时长不变。既有接触时间、命中／血量／倒下同步及连续受击回归继续保留。

这批是固定站位样板验收，不替代真实3v3、全部体型和桌面混战可读性阶段。浏览器使用Chrome／SwiftShader，不代表真实显卡性能。

## 验收记录

第一版水流方向和水花通过；空手劈因主斩痕太细、粉色碎片抢眼退回，已改为收尖短弧并减少碎片。光束因起始阶段太淡退回，已增加主束最小宽度并缩短点亮过程。

用户随后明确只保留一套视觉标准：移除设置页的减少闪烁与镜头档位、浏览器偏好模块、共享设置契约，以及世界、转场、特效池、闪电与镜头的档位分支。旧本地设置不再读取；正式世界与战斗均使用标准表现。固定技能采样只过滤镜头cue以保持前后构图一致，正式游戏镜头不受此测试过滤影响。

产品复核发现反向快龙在动作切换时被压成细线。根因是带朝向符号的横向缩放经过零点；现仅平滑尺寸绝对值，朝向符号直接切换。新增两物种双朝向、每10ms动作过渡检查，并在全部浏览器样本中记录双方横纵缩放比例，防止角色消失被特效数量检查漏过。

最终验证：

- `npm run typecheck`、`npm run smoke`、`npm run build`：最终转向修复后全部通过。
- `npm run visuals:battle -- --skills-only`：最终24样本全部通过，报告时间 `2026-09-07T02:55:31.523Z`；光束四相位的角色缩放比例约0.97–1.05。
- `npm run visuals:battle`：单标准改造后完整回归通过，报告时间 `2026-09-07T02:45:51.106Z`；覆盖六轮场景进出、五地形、60秒运行、命中与倒下同步、密集战斗及异常／脚部，控制台错误为空。随后转向修复由上述逐帧与24样本专项验证。
- `npm run playable:browser`：通过；覆盖倍速、暂停、跳过、捕捉／放生／败北返回、窄屏布局及设置页。注入旧浏览器视觉偏好后，设置页不再出现两组选项。首次窄屏败北用例未产生预期结果，固定验收个体随机输入并增加胜者断言后通过；未修改正式战斗胜负规则。

最终产品独立验收通过：反向光束飞行与命中时快龙轮廓完整，最新24个标准样本通过；正式页面窄屏败北返回、旧偏好无效及页面错误为空均已核实。本轮无剩余阻断项。
