# 战斗加载收尾

## 需求与边界

角色和背景资源较慢时，战斗先显示配置化兜底角色，继续消费实时表现快照和技能事件；素材就绪后替换美术，保持当前角色与战斗进度。沿用已有失败兜底，不新增加载页面或改变战斗规则。

## 实现

`BattleStage.enterBattle` 在等待图片前安装角色，迟到背景只更新环境。Vue 在等待期间持续提交快照和增量Cue，并对已消费的同一批Cue去重，避免初次挂载的异步流程完成时重复播放。

## 验证（2026-09-07）

- 类型检查、冒烟测试、生产构建通过。
- 生命周期测试补充：资源挂起时角色已存在，更新生命状态并播放反馈；放行后角色对象、最新生命状态和效果数量保持不变。既有测试覆盖等待中退出、重入、旧加载不得覆盖新场景及初始化失败后恢复。
- 发布构建的隔离浏览器测试通过：全部美术等待时4名兜底角色可见；角色先加载、背景仍等待时战斗可绘制；背景迟到后角色数量保持；退出无残留战斗容器，无页面错误。
