# 开发与验收

先读 `PROJECT_RULES.md`、`README.md` 和 `当前美术规范.md`。每阶段完成开发、相关测试、产品验收和本地 Git 提交；推送与部署单独按用户指令执行。

## 低负载执行

检查与构建统一经过 `scripts/run.mjs`，同项目跨进程排队。Windows 使用低优先级、最多 2 个逻辑核心；浏览器批次结束后关闭实例，休息 3 秒再继续。不要同时启动多组重验证，也不要边跑浏览器边改前端源码。

完整战斗分为主体与异常/接触两批；场景截图按桌面尺寸分三批。取消只清理本次验证的进程树。总报告要求同一运行编号且批次完整成功。

## 产品验收要求

- 桌面 1366×768、1440×900、1920×1080：画布随窗口更新、只有一个实例、四边连续；菜单、HUD、入口和主要动作区可用。
- PMD 角色动作连贯、脚点稳定、转向不压成细线、弹体从正确挂点发出；正式入口过场至少1秒，资源齐备才开始，10秒未就绪提示网络异常并返回原入口。等待与取消不能改变战斗结果或存档。
- 命中、扣血、异常、控制解除和倒下保持同步；自然结算等待演出结束，经验和捕捉不重复结算。
- 多人混战保留目标轮廓和异常标记；战场始终固定全景，出招和倒下不引起震屏、平移或缩放；普通连续受击不打断施法，真实中断清除蓄力。
- 世界建筑与立柱有承托，水岸和岩面有厚度与层次，入口和路径对应真实地图；美术清理不改动地图、碰撞或战斗数值。
- 退出后画布、计时、帧任务、观察器和特效正常释放，控制台无错误。

## 产物管理

截图、候选图、报告和临时编译文件不提交 Git，可在不运行验证时清理。产物目录为 `doc/visual-baselines/`；删除后先生成新证据，不把缺失基线当作通过。

完整战斗以本次 `battle/suite-report.json` 为准。浏览器使用独立 Chrome 和隔离数据；SwiftShader 用于功能与画面回归，不能充当原生 GPU 性能结论。截图抽验与全量结构校验分别报告，不宣称逐帧穷举全部角色。

## 天气与条件特性

`node scripts/run.mjs battle-effects-report`：厚脂肪与属性抗性独立减伤、无防守双向命中、天之恩惠不降低原概率、避雷针实际触发、分层护盾消耗/到期、临时速度不扣除永久等级、初始异常到期，以及天气覆盖/刷新/到期、气象台抑制和倒下恢复、天气代价、终局清理、条件文字启停与去重。

`node scripts/run.mjs playable-browser-report --weather-only`：正式战斗四种天气圆标切换、顶部中央位置和条件提示运行。天气与角色提示沿引擎 → 延迟表现 → HUD/Pixi 链路呈现；自身生命代价不播放受击动作。

天气规则配置在 `packages/config/src/battle-weather.ts`：晴、雨、雪、沙暴持续20秒；初始默认无天气，新天气覆盖，同类刷新。幻境之塔二至五层显式配置雨/沙/晴/雪；日照登场覆盖为晴。暂停不推进天气，倍速随模拟时间推进，终局清理。不增加全屏天气特效或全体天气伤害、火水威力乘区。

气象台在场时抑制双方天气效果、时长继续，倒下恢复。叶绿素晴天速度×1.5；太阳之力晴天攻击×1.5且每秒消耗1%最大生命；雨盘/干燥肌肤雨天回复；干燥肌肤晴天直接承伤×1.25；沙隐/雪隐仅对应天气增加20%闪避。属性与伤害估算复用实际战斗规则，不写回存档常驻属性。

毅力、神奇鳞片及上述天气增益在条件进入/退出时分别显示一次角色上方文字，不持续刷屏、不附带环形光效。太阳之力生命代价仅同步血量和必要倒下。

空特性采用简单战斗规则：发光提高命中；迷人之躯在近战受伤时概率降攻；诅咒之躯在直接受伤时概率降速，两者有6秒触发冷却和等级下限；潮湿减免火伤；应变体质提高防御；磁力提高对钢属性目标的伤害；连攻提高首招冷却回复；紧张感提供登场冷却压制；轻快提供登场短时速度。保留实例特性标识，名称和说明只展示当前效果。

`battle-effects-report` 同时覆盖上述九项规则、实际伤害与护盾触发边界、同属性被动、必中概率、AI 不受目标黏性/集火驱动而空打免疫目标，以及太阳之力生命代价下的选招。AI 共用实际命中、减伤、目标加成和首招冷却规则，保持既有距离约束。

玩家文案遵守 `PROJECT_RULES.md` 第三节：介绍、悬停提示、状态和错误使用中文，只描述实际规则。详情与图鉴的基础冷却共用 `TACTICAL_COOLDOWN_SCALE`，首招读取物种配置，战斗卡显示实际冷却；程序接口、素材署名、玩家名称与按键不做中文替换。

`node scripts/run.mjs playable-browser-report --copy-only` 检查队伍、炼妖、图鉴、设置、切磋与详情页面的中文文案，并检查1366×768下实际招式悬停的内容与窗口边界。`--hud-only` 检查三桌面尺寸的完整战斗卡、首招顺序、冷却、控制与暂停变化。

## 战斗空间回归

`node scripts/run.mjs battle-regression-report`：终局残留蓄力清理、投影双向与友疗朝向、收招方向保持、默认左下/右上开场、全合法格 × 五环境 × 三桌面尺寸的 HUD 余量，以及毅力/神奇鳞片的无异常、异常、解除和大力常驻加成对照。`node scripts/run.mjs playable-browser-report --ending-only` 在正式页面保留我方蓄力，由队友消灭敌方，验证无需点击结算即可自动弹窗。

`battle-browser-report --spacing-only` 同时检查三桌面尺寸实际身体边界与 HUD 留白，并验证蓄力中结束后 Pixi 能完成收尾。取景保持固定；朝向按同一投影计算，显示动作目标不参与命中规则。

使用 `node scripts/run.mjs battle-space-report` 串行验证近战、混合、远程与围攻 12 场固定种子对局、完整复现、各性格优势距离、连续脚点跨界、闪避与特性免疫附加效果。近战成员必须都有输出，远程不能因残血目标坍缩为贴脸追击。

使用 `node scripts/run.mjs battle-browser-report --spacing-only` 检查 1366/1920 桌面实际站位、1440 桌面喷火龙蓄力/释放/打断。范围指示随快照移除，火焰终点遵守七格射程，分辨率不得改变战斗事实。

## 基础招式、速度与治疗

范围避让专项：`node scripts/run.mjs battle-evasion-report` 检查扇形、直线、周身、落点范围的成功出界与失败命中、两步连续移动、动作锁、无路、反应不足、打断、性格和血量决策、真实模拟伤害与复现，以及新威胁取消路线、不同释放时间和窄范围路径穿越。

参数位于 `packages/config/src/battle-evasion.ts`。每次蓄力只判定一次，尝试间隔 1.4 秒，最多移动两步；速度通过既有移动间隔影响能否赶上，不缩短招式前摇。躲避只使用公开蓄力和锁定方向，不能打断自己的动作；路径复用正式碰撞规则。新危险使旧路线失效时停止该路线，不立即反复重规划。专项覆盖引擎事实；画面使用既有快照移动链路，通过 spacing 浏览器专项检查。

`node scripts/run.mjs battle-tempo-report`：151 物种基础招式与四配招分离；相同角色速度 20/80/200/极端值的实际释放数；基础与战术 CD 的不同收益、阶段/麻痹、动作占用与停步；友疗/自疗/满血/死亡/远距目标；高速远程仍能被近战接敌；种子 47 的混合治疗与三治疗阵容必须自然结束。

`node scripts/run.mjs battle-browser-report --tempo-only`：1440×900 串行检查喷火龙、怪力、皮卡丘、胡地、吉利蛋连续六秒出招，记录动作队列，截图起手/释放/衔接，HUD 只显示基础及战术招式与实际冷却秒数。

治疗量使用施法者有效攻击与 healingPower，不按受疗者最大生命放大；持续回复按攻击换算，满血不累计回复储备。基础冷却约 2–3.2 秒，速度分别通过基础/战术曲线缩短，统一出招占用限制实际最高频率，CD 增益变化保留已完成进度。

## 队伍协作

`node scripts/run.mjs battle-cooperation-report`：有效缺血、承压优先、双基础治疗实际分工、施法预约失效与重伤合救、保护目标不被粘性/分流覆盖、远处威胁不追逐、叠加控制取最长时长与控制窗口选敌。同时运行 tempo、space、smoke，确认续航残局收束、作战距离和动作占用保持有效。

协作参数位于 `packages/config/src/battle-cooperation.ts`。治疗预约只统计已经开始且即将完成的有效施法；即时治疗由真实血量更新协调。支援者天生攻击优先远程，避免只能近身进攻而在后排永久等待。协作评分不提供额外伤害或治疗加成。

## 技能释放与命中表现

技能选择专项：`node scripts/run.mjs battle-decision-report` 检查聚集/分散选招、移动趋势和性格风险、残血快速收尾、基础冷却时继续进攻、恢复与前摇影响打断窗口、精神力免疫，以及正式模拟击倒和事件复现。参数位于 `packages/config/src/battle-decision.ts`；只估计已开始的当前格缓动，不预测下一步或随机避让。控制不会取消当前格缓动。空间专项保留双坦克残局自然结束检查；同时运行 tempo、cooperation、evasion、smoke 和类型检查。

`battle-browser-report --tempo-only` 增加五角色双朝向与八秒 3v3 混战抽样。`battle-readability-smoke.ts` 检查单次近战结果只出现一次冲击、治疗两端分离、真实身体挂点及局部碎光回收。截图抽样不等于全部物种逐帧验收。
