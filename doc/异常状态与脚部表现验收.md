# 异常状态与脚部表现验收

> 历史验收记录：文中的双模式证据对应当时版本。2026-09-07 起按用户要求统一视觉与镜头标准，减少闪烁模式已移除。

## 用户要求

替换敌方蓝色光环及其他装饰环；燃烧表现为身上多处小火苗；异常状态整体换成符合宝可梦素材的像素风，同时优化地形对脚部的遮挡。

## 实现

- 燃烧：错开明灭的小簇红橙火苗；中毒：深浅紫烟；麻痹：少量短电弧；冰冻：局部冰晶。睡眠、混乱、眩晕分别用头顶 Z、问号、星标，抵消朝向镜像，保证可读。
- 状态和俯冲包裹使用身体局部坐标，依据已加载纹理的透明边界适配大小体型；配置最小屏幕像素，避免远处角色特效缩成不可辨的点。
- 移除代表模型的常驻灰色菱形与光环装饰；通用范围、蓄力、水花的装饰圆环改为分散元素细节。
- 草叶仅遮脚底窄带，归属每个角色并随其深度排序；阴影按实际可见脚底和体宽定位。飞行、悬浮、抬升及倒下不生成脚部草叶，切换水地或洞穴清理草带。
- 全部属于 renderer／静态美术配置调整；不改 engine、状态结算、伤害、技能数值或权威移动。使用已有 manifest 资产，无新增素材来源。

## 验收方法

`npm run visuals:battle -- --natural-only` 使用正式 BattleStage、隔离 DTO 驱动固定场景，生成 `doc/visual-baselines/battle/natural-report.json` 及截图：

| 场景 | 检查 |
| --- | --- |
| 同体型异常对照、单独眩晕 | 不依赖标题仍能辨认，符号方向正确，无全身圆环 |
| 大小体型燃烧／移动 | 多处火苗贴身，身体轮廓可辨 |
| 清除／倒下 | 状态图形清空，无常驻灰钻造成误判 |
| 草地／水地／洞穴 | 脚底与阴影贴合，草带不遮腹部、不跨角色排序 |
| 密集火水精神及电系范围 | 每批27个反馈完整播放，结束全部释放；标准与减少闪烁模式均采样 |

完整 `visuals:battle` 另覆盖动作时序、伤害同步、控制恢复、窄屏与反复进出生命周期。浏览器使用 Chrome／SwiftShader；这些结果不等同于真实显卡性能或全部151种体型的人工美术验收。
