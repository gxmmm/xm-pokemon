# 大体型战斗可读性验收

日期：2026-09-07。本轮优先处理桌面全窗口下的同列角色堆叠，保留单一视觉标准。

## 产品范围

默认 3v3 的开场、0.55 秒移动和 3 秒停靠样本需能辨认全部六只；小体型头部与主要轮廓不能被大体型完全吞没。允许自然的局部交叠，极端自由摆位同点不承诺零遮挡。

初始证据显示，同队停靠两格已经生效，但正对纵列的镜头把前后距离压缩到约 45 像素，大体型角色仍会覆盖后方角色。因此本轮不扩大引擎间距，不修改自由阵型、射程、移动速度、碰撞和技能结果，也不通过单独挪动角色的显示位置规避实际空间规则。

## 最终实现

- 所有环境统一使用 35° 水平斜角，保留 50° 俯视角。旋转发生在共享世界投影中，角色、地面锚点、悬空高度和技能挂点使用同一坐标转换。
- 调整各环境镜头高度，旋转后全部可用格仍在原地面安全范围内，保留前景与头顶留白。
- `BATTLE_BODY_DISPLAY` 按不透明身体设置 100 像素宽、92 像素高的显示上限，尺寸预算在透视和动作形变之前应用。小体型不缩小，大体型保持等比；透明边缘不占预算。
- 身体尺寸取稳定接触参考帧，避免按逐帧轮廓反复缩放；动作、异常效果、阴影和身体挂点共同使用调整后的尺度。未增加物种或技能 ID 分支，未添加美术资产。

对照曾比较正负 22°、35° 和 82/92 像素上限。产品认为 35° 更利于辨识，而 82 像素对主要遮挡改善有限，因此最终保留 92 像素及大体型差异。

## 产品验收边界

独立产品已查看最终三尺寸九张站位截图，并抽查连续受击、范围特效及草地边缘，视觉验收通过，无剩余视觉阻断。六只均可辨认，皮卡丘与卡比兽仍有局部交叠，但头部外形、耳朵和外侧躯干保留，未回到旧图被完全吞没的状态；特效下仍能识别目标，边缘角色完整。

截图与浏览器回归使用 Chrome / SwiftShader，不代表真实显卡性能。固定轨迹不穷举全部 151 种体型、技能组合和自由阵位，也不把静态可辨认等同于所有动态时刻完全无遮挡。
