# 喷火龙纯代码动作小样

这是验证“能否用代码画出可辨认角色和关节动作”的独立研究，尚未替换正式战斗素材。

- 绘制方式：Python / Pillow，多边形像素轮廓、固定调色板、头颈／下颚／翼／手臂参数插值。脚部坐标固定，不对整张角色图做旋转或拉伸。
- 视觉参考：项目已有 `apps/web/public/sprites/pokemon/6.png`；生成脚本不读取或拼贴该图片，也未调用图像生成服务。角色设计归原权利方；代码绘制不意味着角色设计变为原创。
- 输出：128×128 RGBA 四姿态与横排帧集、三倍最近邻预览、放慢播放的 GIF。`study.json` 给出四张姿态的脚点和嘴部参考点。
- 重新绘制：在项目根目录运行 `python -X utf8 scripts/draw-charizard-motion-study.py`，需要 Pillow。
- 样例顺序：待机 → 收颈蓄力 → 张嘴释放 → 后坐恢复；循环回到待机。GIF 的演示速度不代表游戏动作、施法或伤害时间。

## 检查

四张图均为真实透明底，无边界裁切；两只脚的像素区域一致；GIF 可循环播放。插值序列末帧回到待机参数。

产品独立检查四姿态图与挂点记录后，认可作为代码绘制可行性小样交付，不通过正式素材替换验收。主要差距：头吻偏长、身体偏瘦、翼膜几何感强、张口下颌偏方、颈肩衔接生硬。GIF 已完成文件检查与抽帧检查，产品未目视确认其连续播放效果。

## 使用范围

代码小样展示了动作可控性，但当前轮廓较几何化、阴影简化，与现有素材的精细像素风仍有差距。仅做了一个观察角度，没有制作背面或完整动作库；嘴点也尚未通过正式战斗特效联验。不加入正式 manifest，不替换 flame-wing-v5。

其他角色可以复用导出和播放流程，但轮廓、关节、遮挡和关键姿态仍需分别绘制。
